# 오늘의 진짜 정보판 — 원/달러 환율 (과제 4)

매일 바뀌는 USD/KRW 환율 한 값을 기록하고, 그 값이 언제·어디서 왔는지 함께 보여주는 정보판입니다.

## 공개 심사 주소

- 결과물: https://terran1234.github.io/daily-board-04/
- 소스: https://github.com/terran1234/daily-board-04

로그인·계정·비밀키 없이 열립니다.

## 카드 1 — 값이 뜻하는 바

| 항목 | 내용 |
|---|---|
| 값 | 달러(USD) 1개를 사는 데 필요한 원화(KRW) |
| 단위 | KRW per 1 USD |
| 출처 | ExchangeRate-API 공개 엔드포인트 `https://open.er-api.com/v6/latest/USD` (키 없음) |
| 출처 시각 | 응답의 `time_last_update_unix` — 출처가 값을 갱신한 때 |
| 조회 시각 | 이 화면(또는 기록 스크립트)이 값을 받아온 때 |
| 기준 시간대 | KST (Asia/Seoul, UTC+9) |

출처 시각과 조회 시각은 다른 시각입니다. 출처는 하루 한 번쯤 갱신하고, 화면은 열 때마다 조회합니다.

## 정상 한 건의 원자료 · 저장값 · 화면값 대조

2026-09-30 KST에 받은 정상 응답 한 건입니다. 세 값은 같습니다.

| 단계 | 어디에 있나 | 값 | 시각 |
|---|---|---|---|
| 1. 원자료 (받은 그대로) | [`data/raw/2026-09-30.json`](data/raw/2026-09-30.json) 의 `rates.KRW` | `1353.681844` | `time_last_update_unix` = `1790726551` → 2026-09-30 09:02:31 KST |
| 2. 저장값 | [`data/latest.json`](data/latest.json) 의 `value` | `1353.681844` | `source_time_kst` = `2026-09-30T09:02:31+09:00`, `fetched_at_kst` = `2026-09-30T16:06:33+09:00` |
| 3. 화면값 | 결과물 화면 "정상 한 건 대조" | `1,353.68` | 출처 시각 2026-09-30 09:02:31 KST |

- 원자료 − 저장값 = 0
- 화면값 규칙: 저장값(전체 자릿수)을 소수 둘째 자리까지 반올림해 표시합니다.
- 화면은 이 저장 기록을 실제로 읽어 와 세 값이 같은지 스스로 확인하고, 다르면 "일치하지 않습니다"를 띄웁니다.

## 파일 구성

```
index.html              정보판 화면 (실시간 조회 + 저장 기록 대조)
scripts/record.ps1      정상 응답 한 건을 원자료 그대로 + 저장값으로 남기는 스크립트
data/raw/YYYY-MM-DD.json  받은 그대로의 원자료 (KST 날짜별)
data/latest.json          저장값 (값, 단위, 출처, 두 시각, 시간대)
```

`record.ps1`은 응답이 `success`가 아니거나 KRW 값이 없으면 아무것도 저장하지 않습니다.
